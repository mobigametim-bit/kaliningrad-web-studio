# Kaliningrad Web Studio

Демонстрационная площадка персонализированных сайтов для локального бизнеса Калининграда. Репозиторий содержит **только публичные демоверсии**, не базу потенциальных клиентов и не исследовательские досье.

## Структура

- `index.html` — нейтральная главная без каталога демо.
- `demos/coffee-8f2a91c4/index.html` — демонстрационный концепт вымышленной кофейни.
- `demos/auto-b7c40e92/index.html` — демонстрационный концепт вымышленного автосервиса.
- `robots.txt` / `noindex` — просьба не индексировать страницы (не контроль доступа).
- `.nojekyll` — статическая публикация GitHub Pages.

Сайты автономны: HTML + CSS + встроенная векторная графика; без внешних шрифтов, скриптов и карт. Демо-функции не принимают реальные заявки. Не публиковать реальные конфиденциальные контакты, частные заметки, чужие отзывы целиком и изображения с неустановленными правами.

## Публикация

В репозитории: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

После успешного включения Pages ожидаемые адреса:
- `https://mobigametim-bit.github.io/kaliningrad-web-studio/`
- `https://mobigametim-bit.github.io/kaliningrad-web-studio/demos/coffee-8f2a91c4/`
- `https://mobigametim-bit.github.io/kaliningrad-web-studio/demos/auto-b7c40e92/`

## Добавление организации

1. В приватной таблице подтвердить карточки, адрес, актуальность организации и поиск собственного сайта.
2. Собрать досье из публично доступных сведений; отметить источники и права на фотографии.
3. По команде пользователя создать отдельную папку `demos/<slug>-<random-id>/` и полностью самостоятельный дизайн.
4. Поставить видимое «Демонстрационный концепт. Не официальный сайт организации». Не включать фиктивные отзывы, цены, акции, квалификации.
5. Протестировать открытие без сервера, мобильную версию, локальные ссылки. Ссылку и коммерческий статус хранить **только в приватной Google Таблице**.
6. После согласия компании внести утверждённые материалы и передать финальную сборку / перенести на отдельный хостинг.

**Важное ограничение:** публичный репозиторий GitHub раскрывает HTML и всю включённую графику. Случайный доступ можно уменьшить неиндексируемыми путями, но нельзя предотвратить копирование. Отправляйте видео/скриншоты вместо исходников, если это существенно.
