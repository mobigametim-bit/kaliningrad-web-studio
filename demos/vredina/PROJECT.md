# Vredina — дизайн-концепт сайта салона красоты

## Задача
Собрать самостоятельный демонстрационный сайт Vredina на основе большого набора изображений, загруженных пользователем в GitHub. Дополнительная генерация изображений не требуется.

## Публичные сведения
Основная актуальная сверка:
- Яндекс: карточка Vredina подтверждена владельцем, рейтинг 4,9, адрес отображается как Москва, Напольный пр., 2/21, график ежедневно 10:00–21:00.
- Телефон +7 (906) 760-12-21 дополнительно совпадает в нескольких каталогах.
- Публично подтверждаются направления: маникюр/педикюр, стрижки и окрашивание волос, брови и ресницы. Более широкий перечень процедур не фиксируется на лендинге без согласования.

Источники:
- https://yandex.ru/medicine/clinic/vredina_200968038469
- https://2gis.ru/moscow/geo/70000001030376989
- https://chenado.ru/moskva/krasota/studija-krasoty-vredina-na-svobodnom-prospekte
- https://moskva1.jsprav.ru/lechenie-i-vosstanovlenie-volos/vredina-1/

Примечание по адресу: часть каталогов использует вариант «Свободный проспект, 21/2», часть — «Напольный пр., 2/21». На концепте выбран вариант из подтверждённой владельцем карточки Яндекса; перед коммерческим запуском адрес нужно согласовать с салоном.

## Фотографии
Пользователь загрузил 25 PNG-файлов в:
`assets/originals/`

На сайте используются только эти материалы. Генеративные изображения и внешние стоки не добавлялись.

Исходники имеют имена скриншотов; они сохранены без переименования, чтобы не создавать бинарные копии и не увеличивать репозиторий. Публичная страница подключает их относительными путями.

## Арт-дирекшен
Vredina не повторяет Beauty&Health, Beautique или Beauty V Teme.

Концепция: **«редакционная дерзость»**.
- тёплый кремовый фон вместо стандартного стерильного белого;
- чёрный как основной контраст;
- яркий розовый как акцент;
- кислотно-лаймовый используется точечно;
- крупный геометрический display-шрифт Unbounded + Manrope для текста;
- асимметричные фото в hero;
- плотная мозаичная галерея;
- короткие, разговорные русские тексты;
- никаких цен и неподтверждённых рекламных обещаний.

## UX
1. Верхний юридический дисклеймер.
2. Hero с названием, основными направлениями, адресом, графиком и звонком.
3. Три подтверждённых направления услуг.
4. Короткий смысловой блок вместо рекламного полотна.
5. Большая галерея из предоставленных изображений.
6. Контакты и переход к маршруту.
7. Полный блок «О статусе сайта».
8. Фиксированная кнопка звонка на мобильном.

## Техника
Статический HTML/CSS/JS:
- `index.html`
- `styles.css`
- `script.js`
- adaptive 320/360/390/768/1280+;
- mobile menu;
- lightbox: мышь, Escape, стрелки;
- lazy loading галереи;
- error fallback для недоступного изображения;
- reduced motion;
- noindex/nofollow/noarchive.

## Правовые границы
- Концепт неофициальный и не принимает заявки/оплату.
- Телефон ведёт непосредственно на публичный номер организации.
- Не публикуются цены из агрегаторов.
- Не публикуются имена мастеров и отзывы как рекламные цитаты.
- Перед коммерческой передачей нужно подтвердить права на фотографии, согласия изображённых людей и финальные сведения о бизнесе.
