# Beauty V Teme — исходные фотографии

Сюда загружаются оригинальные фотографии для дизайн-концепта салона красоты Beauty V Teme (Москва, Братиславская улица, 16к1).

## Как загружать
GitHub → Add file → Upload files. Можно загружать большими партиями.

Оригинальные имена файлов менять не нужно — после загрузки изображения будут просмотрены, отобраны и переименованы по содержимому без генерации новых картинок.

## Что особенно полезно
- интерьер и общий вид салона;
- рабочие места и детали пространства;
- стрижки, окрашивания, укладки;
- маникюр / брови / ресницы / другие реально оказываемые услуги, если они есть;
- мастера за работой;
- вывеска, логотип, фирменные материалы;
- детали, которые передают характер салона.

## Правило проекта
Для этого концепта используем реальные фотографии. Генерировать изображения не нужно, пока собственного материала достаточно.

Не загружать материалы, на публикацию которых нет разрешения, и лишние персональные данные клиентов.
