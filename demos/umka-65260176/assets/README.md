# Умка — исходные фотографии и фирменные материалы

Материалы для детской парикмахерской «Умка», Альметьевск. Папка предназначена для исходников будущего персонального дизайн-концепта.

Загружайте сюда фотографии через GitHub → Add file → Upload files. Можно несколько файлов за раз. Оригинальные имена сохраняйте, переименую и оптимизирую при сборке сайта с сохранением исходников.

Подходящие материалы:
- дети во время стрижки, причёски и результат работы (с разрешения родителей/законных представителей на публикацию);
- интерьер, детские кресла, игровые детали, инструменты и зона ожидания;
- вывеска, логотип, фирменные цвета;
- если есть — фотографии сотрудников с разрешением.

**Важно:** генеративные изображения для сайта не использовать: задача — реальная детская парикмахерская с акцентом на детей. Не загружать чужие фотографии из карт/соцсетей без права на публикацию. Не коммитить персональные данные детей.

Фотографии из 2ГИС — источник для анализа, но не доказательство права на использование.

До появления файлов и утверждения UX сайт и карточку портфолио не публиковать.
